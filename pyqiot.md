### Questions

#### Q1.
**A.** A smart university classroom deploys a battery-powered occupancy sensor (powered at $3.7\text{ V}$, $2400\text{ mAh}$ Li-ion cell). The sensor has two modes of operation:  
- **Active mode:** Current = $25\text{ mA}$ for $1\text{ second}$ every $2\text{ minutes}$ (for sensing + wireless transmission).  
- **Sleep mode:** Current = $80\ \mu\text{A}$ otherwise.  
Assume continuous operation and that the battery is only used for this device. **[5 Marks]**  
a. Calculate the average current consumption ($\text{mA}$) of the occupancy sensor.  
b. Estimate the device lifetime (hours, days, and years) with the given battery.  
c. If the classroom requires $40$ such sensors, estimate the total number of battery replacements needed in $3\text{ years}$ of operation.  

**B.** A temperature sensor transmits data every $30\text{ seconds}$ with each packet of size $250\text{ bytes}$, while a light sensor transmits data every $10\text{ seconds}$ with each packet of size $90\text{ bytes}$. Find the number of packets generated by each sensor in $24\text{ hours}$ ($86,400\text{ seconds}$), and compute the total data generated. **[5 Marks]**
