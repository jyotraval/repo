ContestUnify — The Unified Contest Dashboard
an Activity Diagram for contest aggregation + AI insights
AIM
The aim of this Activity Diagram is to illustrate the end-to-end process of the Contest Unify platform — how upcoming and live contests are aggregated from multiple external platforms (Codeforces, LeetCode, CodeChef), cached in Supabase, displayed on a unified dashboard, and how a student-supplied Codeforces handle flows through the Gemini 1.5 Flash chatbot to produce AI performance insights.
Problem Statement
Designing an automated system Contest Unify to fetch contest metadata from multiple competitive-programming APIs, normalise formats, store in a cloud database, and display role-based views (upcoming vs live contests) on a single dashboard — while integrating a Google Gemini 1.5 Flash chatbot for Codeforces-handle-based performance analysis, handling API errors, and ensuring data freshness & insight persistence.
Scope
Covers: contest aggregation, caching, dashboard display, AI insight retrieval, and insight history persistence. Out of scope: user authentication, payment gateways, and integration with external learning-management systems.
Activity Diagram — Contest Unify
Conclusion
The activity diagram for Contest Unify visualises the automated contest-aggregation & AI-insight flows — fetching contest metadata from multiple platform APIs, caching in Supabase, displaying the unified dashboard, routing the student's Codeforces handle through Gemini, persisting insights, and looping back for the next query. It ensures efficient data management, error resilience (invalid-handle & API-failure retries), and role-free student access to AI performance feedback.

RepoViz — The Python Code Visualizer
an Activity Diagram for the 4-stage parsing & graph pipeline
AIM
The aim of this Activity Diagram is to illustrate the end-to-end process of the RepoViz pipeline — how a Python project path supplied on the command line is scanned for .py files, parsed via the AST module into CodeElement instances, transformed into a NetworkX directed graph with import-resolved call edges, and finally rendered through Graphviz into PNG / SVG / DOT output files.
Problem Statement
Designing an automated tool RepoViz to scan any Python codebase, extract classes / functions / methods / module-level code, resolve import aliases, build a directed call graph, and render hierarchical visualisations (hybrid / flow / simple / standard styles) — while respecting ignore patterns (venv, tests), detecting entry points, and supporting multiple output formats.
Scope
Covers: CLI parsing, recursive .py file discovery, AST extraction, alias resolution, NetworkX graph construction, and Graphviz rendering. Out of scope: cross-language projects, runtime call profiling, and live editor integration.
Activity Diagram — RepoViz
Conclusion
The activity diagram for RepoViz visualises the automated 4-stage pipeline — CLI parsing & path validation, recursive .py discovery with ignore patterns, AST extraction of CodeElements, NetworkX graph construction with import-alias resolution, and Graphviz rendering of PNG / SVG / DOT output files. It ensures efficient code-structure analysis, graceful error handling (invalid path, no files, format errors), and flexible output-format selection for visualising any Python project.
